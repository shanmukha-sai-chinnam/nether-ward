Nether Ward: Static Security Scanner and Adversarial Evaluation Harness

High-assurance security runtime, static analysis engine, stdio MCP tool proxy, ephemeral Linux namespace sandbox, and synthetic adversarial harness for autonomous AI agents. Built in pure compiled Rust with hermetic Nix flake reproducibility.

PILLAR I src/sast.rs
SAST & Syntactic De-Obfuscation

Deterministic regex and abstract pattern scanner. Intercepts hardcoded credentials, dynamic execution (eval, exec, os.system), reverse shells, and reflection evasion (NW-OBF-001..004).

PILLAR II src/threat.rs
Shannon Entropy Threat Profiler

Computes global Shannon entropy and 256-byte sliding window entropy ($H(X) \ge 7.20$ bits/byte) to identify embedded binary shellcode, packed stagers, and obfuscated payload blobs.

PILLAR III src/mcp.rs & gateway.rs
Stateful MCP Proxy & Gateway

Bidirectional stdio JSON-RPC proxy and OpenAI-compatible HTTP firewall. Correlates multi-turn tool invocations (NW-MCP-005 drop-and-execute, NW-MCP-006 sensitive read to exfiltration).

PILLAR IV src/canary.rs
Canary Tokens & Decoy Tripwires

Plants synthetic credentials and honeypot files in agent context. Instantly flags lateral exploration or memory exfiltration attempts with rules NW-CANARY-001 and NW-CANARY-002.

PILLAR V src/velocity.rs
Velocity Limiter & Dual-Key Gate

Sliding-window execution throttling (NW-VEL-001) preventing runaway loops, and dual-key cryptographic authorization gates (NW-GATE-001) intercepting irreversible mutations.

PILLAR VI src/sandbox.rs
Linux Kernel Namespace Sandbox

Executes agent tool commands inside isolated Linux kernel namespaces (CLONE_NEWNET, read-only root mounts, PID isolation, and dropped capabilities).

PILLAR VII flake.nix & .github/workflows
Hermetic Nix Flake & 14-Stage Sentinel CI/CD

Zero mutable dependencies. 14 discrete GitHub Actions pipeline stages verifying formatting, Clippy warnings (-D warnings), 84 unit and integration tests, sandbox isolation, SAST scans, SBOM generation, and automated documentation deployment.

Mathematical Formulation & Sliding Window

Shannon Entropy Equation:
H(X) = - ∑i=0255 P(xi) × log2 P(xi)

Evaluated over 256-byte windows with a 64-byte sliding stride. While global file entropy can be diluted by large benign headers, sliding window analysis detects localized shellcode stagers at precise byte offsets.

Normal (< 6.0 bits)

Plaintext source code, markdown documentation, standard JSON and YAML configurations.

Elevated (6.0 - 7.2 bits)

Compressed archives, minified JS, high-density binary arrays, or media files.

Critical (≥ 7.2 bits)

Cryptographic ciphertext, packed binary shellcode, memory stagers, and obfuscated backdoors.

Syntactic De-Obfuscation & Reflection Guard

Autonomous agents and red team adversaries evade static signature scanning by disguising dangerous execution through dynamic reflection, string concatenation, and encoded stagers. Nether Ward incorporates dedicated rules detecting evasion tactics:

NW-OBF-001 CRITICAL
Dynamic Reflection Import Interception

Detects getattr(__import__('os'), 'system') and indirect importlib reflection calls.

NW-OBF-002 CRITICAL
Encoded Dynamic Eval Stager

Intercepts exec(b64decode(...)), eval(atob(...)), and in-memory byte execution pipelines.

NW-OBF-003 HIGH
String Concatenation Evasion Sink

Flags fragmented execution names like 'os.' + 'system' or 'ev' + 'al'.

NW-OBF-004 CRITICAL
Embedded Base64 Shellcode Stager

Extracts and evaluates embedded base64 chunks exceeding high-density entropy thresholds.

Ephemeral Linux Kernel Namespace Sandbox

        

          Nether Ward executes potentially hazardous tool calls and external scripts inside lightweight, ephemeral Linux namespaces using native kernel primitives (unshare / clone). Zero container daemon overhead, sub-millisecond setup time.
        


        
        

          

            
Network Isolation

            
CLONE_NEWNET drops all egress and ingress interfaces, leaving loopback down.

          

          

            
Read-Only Mounts

            
Host root filesystem bind mounted as read-only; mutations confined to tmpfs.

          

          

            
Process Isolation

            
CLONE_NEWPID isolates process table; target tool cannot inspect or signal host processes.

          

          

            
Dropped Privileges

            
Strips setuid capabilities and runs as unprivileged user nobody.

          

        


        

          
Running Sandboxed Commands via CLI:

          
$ nether-ward sandbox --no-network --read-only-root --timeout 15 -- ./untrusted_script.sh

          
Specification dry-run check: $ nether-ward sandbox --dry-run -- echo test

CLI Subcommands & Operational Manual

        
        

          
          
          

            

              nether-ward threat [OPTIONS]
              Entropy & SAST
            

            
Triage files for Shannon entropy, extract threat strings, or run static security scans.

            

              
--sample <PATH> : Single file entropy and indicator analysis

              
--dir <PATH>    : Batch analyze directory of suspicious samples

              
--sast <PATH>   : Full recursive SAST directory scan

              
--sarif <PATH>  : Export findings to OASIS SARIF v2.1.0

              
--rules         : Print active vulnerability rule definitions

              
--json          : Machine-readable JSON output

            

          


          
          

            

              nether-ward canary [ACTION] [OPTIONS]
              Canary & Honeypot
            

            
Manage in-context canary credentials and audit payload strings for tripwire compromise.

            

              
generate        : Issue new synthetic canary token (--type aws|api|path|jwt)

              
scan            : Scan payload string for active canary leaks (--payload <STR>)

              
list            : List registered default tokens and honeypot paths

              
--json          : Output structured JSON report

            

          


          
          

            

              nether-ward gate [OPTIONS]
              Dual-Key Gate
            

            
Evaluate commands against irreversible destructive actions requiring operator approval.

            

              
--command <CMD>      : Target command string to evaluate

              
--token <TOKEN>     : Operator dual-key confirmation signature

              
--generate-token    : Issue new 15-minute cryptographic authorization token

              
--json              : Machine-readable JSON output

            

          


          
          

            

              nether-ward sandbox [OPTIONS] -- <CMD...>
              Kernel Isolation
            

            
Execute child processes in isolated Linux kernel namespaces.

            

              
--no-network        : Unshare network namespace (CLONE_NEWNET)

              
--read-only-root    : Bind mount root as read-only

              
--timeout <SECS>    : Hard execution timeout (default: 30)

              
--dry-run           : Print sandbox specification without executing

              
--json              : Output execution metadata and timing as JSON

            

          


          
          

            

              nether-ward mcp [OPTIONS]
              Stdio Tool Proxy
            

            
Audit configuration files or run transparent stdio proxy with stateful multi-turn tracking.

            

              
--config <PATH>     : Audit .agents/mcp_config.json for security vulnerabilities

              
--proxy             : Run transparent bidirectional stdio proxy

              
--sanitize          : In-flight secret redaction on stdout stream

              
-- <COMMAND...>    : Target child MCP server command and arguments
