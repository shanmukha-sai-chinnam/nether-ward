The 5-Layer Autonomous AI Attack Surface

Autonomous coding agents possess operational agency: they parse untrusted third-party inputs, generate executable code, invoke external tools via protocols like MCP, and interact with the host filesystem. Traditional application security frameworks are structurally blind to non-deterministic, semantic threats. Nether Ward addresses vulnerabilities across all five attack layers:

1. Linguistic Vector

Direct prompt injections, jailbreak tokens, system prompt overrides, delimiter smuggling, and safety filter evasions.

2. Semantic Context

Indirect prompt injections via ingested web data, goal hijacking, context confusion, and malicious markdown embedding.

3. Supply Chain

Pickle deserialization exploits, poisoned model weights, unsafe PyTorch checkpoints, and malicious dependencies.

4. Code & SAST

Synthesized insecure code (eval, os.system, shell injection), hardcoded cloud credentials, and API key exposures.

5. System Execution

Outbound reverse shells, unconfirmed destructive filesystem deletions (rm -rf /), and unauthorized host reconnaissance.

Shannon Entropy Profiling & Byte Triage

Binary stagers, packed shellcode, and encrypted command-and-control backdoors exhibit statistical uniformity drastically distinct from natural language or structured source code. Nether Ward calculates both global Shannon entropy and localized sliding-window entropy across raw byte streams.

Shannon Entropy Mathematical Definition:
H(X) = - ∑i=1n P(xi) × log2 P(xi)

Where P(xi) represents the empirical frequency probability of byte value i (0x00 to 0xFF) across the evaluated byte slice. The result ranges from 0.0000 (homogeneous) to 8.0000 bits/byte (pure uniform random/encrypted data).

Normal Tier < 6.00 bits

Plaintext source code, markdown documentation, standard JSON/YAML configuration formats.

Elevated Tier 6.00 – 7.20 bits

Compressed archives, minified JavaScript, high-density binary tables, compiled assets.

High / Critical Tier ≥ 7.20 bits

Cryptographic ciphertext, packed binary shellcode, obfuscated loaders, memory stagers.

256-Byte Sliding-Window Entropy Engine

Attackers evade global entropy scanners by embedding small (e.g. 256-byte) high-entropy shellcode chunks within large (e.g. 200KB) low-entropy benign files, keeping overall file entropy below 5.0. Nether Ward implements sliding-window analysis with a 256-byte window and 64-byte stride to isolate embedded stagers and report their exact byte offsets.

In-Flight Secret Sanitization & Masking

When --sanitize is active in proxy or gateway mode, Nether Ward intercepts outgoing tool returns and incoming prompts, redacting API credentials in-flight to prevent model context contamination:

- AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
// Sanitized stream delivered into model context:

Active Stdio MCP Security Proxy

Bidirectional stdio JSON-RPC interception between AI agents and local MCP tool servers.

RFC-Compliant

Agents communicate with Model Context Protocol (MCP) servers over standard I/O streams (stdin / stdout). Nether Ward wraps target MCP commands transparently, inspecting each JSON-RPC frame in real-time. Hostile tool calls are blocked at the perimeter without crashing the parent session.

OpenAI-Compatible Runtime Firewall Gateway

Exposes a high-performance HTTP reverse proxy implementing the OpenAI chat completion API. Filters incoming prompts for prompt injections, monitors model completions for secret leaks, and supports real-time Server-Sent Events (SSE) streaming.

POST /v1/chat/completions

Perimeter firewall checks user prompt and tool arguments. Blocks hostile requests with HTTP 403 nether_ward_threat_blocked.

GET /metrics & GET /v1/stats

Declarative Hermetic Nix Packaging

Nether Ward is packaged natively via flake.nix using pkgs.rustPlatform.buildRustPackage. Builds are hermetic, reproducible, and compile the entire package inside an isolated sandbox with zero network access.

# Build hermetic derivation locally:

Nether Ward CLI Command Reference

nether-ward threat [OPTIONS] Threat & SAST Engine

Analyzes files or directories for Shannon entropy variance, localized stagers, and multi-vector SAST flaws.

--sample <PATH> : Target single file for entropy and heuristic analysis
--dir <PATH> : Batch triage all files within a directory
--sast <PATH> : Run Deep Static Application Security Testing on directory
--sarif <PATH> : Export static analysis findings to OASIS SARIF v2.1.0 format
--rules : Display all 20 active threat detection rules
--json : Emit structured machine-readable JSON output
nether-ward gateway [OPTIONS] Perimeter Gateway

Launches an OpenAI-compatible reverse proxy with prompt injection firewall and secret redaction.

--port <PORT> : TCP port to listen on (default: 4000)
--model <NAME> : Default upstream model (default: gemini-flash-lite-latest)
--upstream <URL> : Upstream OpenAI-compatible API base URL
--sanitize : Enable in-flight secret sanitization and credential masking
nether-ward mcp [OPTIONS] MCP Stdio Proxy

Audits declarative configuration files or runs bidirectional stdio proxy intercepting tool calls.

--config <PATH> : Audit MCP configuration file for security vulnerabilities
--proxy : Run active stdio proxy wrapping a child tool process
--sanitize : Enable in-flight secret masking on tool stdout
-- <COMMAND...> : Child MCP server command and arguments to wrap
nether-ward redteam [OPTIONS] Adversarial Harness

Executes automated adversarial benchmarks against model endpoints and generates compliance reports.

--config <PATH> : Path to redteam evaluation YAML configuration
--dataset <PATH> : Path to synthetic probe dataset in JSONL format
--concurrency <N> : Maximum parallel model evaluation queries (default: 4)
--threshold <PCT> : Minimum required test pass percentage threshold
--judge <MODE> : Semantic judge mode ('jev' or 'lexical')

Standard Process Exit Codes

Exit Code Status Name Trigger Condition
0 SUCCESS_CLEAN Execution clean; zero high/critical vulnerabilities or threat indicators detected.

100 BENCHMARK_FAILURE Adversarial red team benchmark pass rate fell below the configured threshold.
